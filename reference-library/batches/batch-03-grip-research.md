## Bounded negative search and rejected matches

Queries included `goblet squat dumbbell hold shaft both hands handle vertical`, `"goblet squat" "handle" "both hands"`, `"goblet squat" "shaft"`, `"goblet squat" "interlock" dumbbell`, and thumb-focused searches for dumbbells and StrongFirst. Search snippets were treated only as leads.

- [Muscle & Strength](https://www.muscleandstrength.com/exercises/dumbbell-goblet-squat) remains the directly located vertical shaft wording: Roger's 2024-01-11 reply reports using both hands on a vertical handle. Formal instructions on that page instead put hands under the dumbbell edges. This batch found no matched first-party vertical-shaft demonstration, so the staff anecdote does not become visual evidence.
- Generic “both hands” results mostly describe upper-head cupping or kettlebell horns, not shaft gripping. Tonal smart-handle and macebell results are different equipment and were excluded.
- [U.S. Army RAW handbook](https://www.benning.army.mil/tenant/75thRanger/content/PDF/RAW%20Handbook%20Final%20v4.pdf) appeared in search with a purported close-up on printed page 89. Direct web opening timed out; no PDF image was inspected. Retain only as an unverified lead, not visual evidence or a verified page locator.
- [StrongFirst heavy goblet article](https://www.strongfirst.com/kettlebell-simple-sinister-tips-for-heavy-goblet-squats/) was reachable in web text. Its existing collateral was not reclassified as reverse-thumb evidence.

Negative result means “not established within this bounded search,” not “the grip does not exist.” Best next evidence remains a clear, rights-appropriate demonstration explicitly showing the vertical shaft hold, plus dedicated reverse and underside views of both head-support hands and both horn-grip hands. No source found here authorizes media redistribution.

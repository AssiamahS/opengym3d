## Interpretation limits

The movement fields paraphrase each linked publisher's instructions and are qualitative authoring notes. They are not measured joint trajectories or approved instruction. A media link establishes an exercise-topic candidate, not a confirmed view, exact implement or hand match.

The sit-up source uses secured feet; the entry retains that support. The core-twist page explicitly captions its second GIF as a dumbbell variation; that second media link is retained. Feet-up versus feet-down remains unresolved. The back-extension page describes optional front chest loading; its linked demonstration filename identifies front loading, but exact load identity and contact still require pixel inspection. Turkish-get-up text permits dumbbell or kettlebell; its generic handheld-weight label intentionally leaves the implement unresolved. Floor L-sit text also allows handles; actual linked-media support must be checked before declaring a visual match. The farmer's walk records carry implements rather than substituting dumbbells. Burpee text includes push-up and jump, unlike simpler squat-thrust variants.

Proposed grip IDs are coarse indexing only; they do not certify closure or contact. `contact-unresolved` is requested from the coordinator for plate/ball/unknown implement cases. The JSON introduces equipment vocabulary for the coordinator to reconcile rather than editing shared catalogs.

The [StrengthLog directory](https://www.strengthlog.com/exercise-directory/) states conditional noncommercial reuse with attribution. This batch records links only and grants no redistribution rights. NASM, ACE and LIVESTRONG media retain publisher ownership; public availability is not an asset license.

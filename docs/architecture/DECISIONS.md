# Architecture decisions

Accepted records describe choices already made for the project. Proposed records are **not** human approval. Revisit a decision when evidence conflicts with it rather than silently changing the architecture.

| ADR | Status | Subject |
| --- | --- | --- |
| [ADR-0001](ADR-0001-independence-and-reuse.md) | **Accepted / existing direction** | Independent Studio, reuse OpenGym pipeline, minimal local-first architecture |
| [ADR-0002](ADR-0002-deformation-derivative-gate.md) | **Proposed / needs review** | Criteria for adopting anatomy/weight/volume derivatives |

Create a new record from [ADR template](../templates/ADR.md) only for a lasting, consequential choice. Small implementation details belong in the relevant milestone report or code comments.
